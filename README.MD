## ✨ ویژگی‌های نسخه جدید

- 🎨 **رابط کاربری کاملاً مدرن** با طراحی Dark Mode و تم رنگی نارنجی جذاب
- 🖼️ **گالری تصاویر هوشمند** با قابلیت انتخاب، مرتب‌سازی و پیش‌نمایش سریع
- ⚡ **عملکرد فوق‌العاده سریع** با سیستم کش دوگانه پیشرفته
- 📱 **نمایش بهینه‌شده** با صفحه‌بندی (Pagination) هوشمند
- 🔧 **تنظیمات کامل** شامل کنترل اندازه تصاویر، نرخ فریم و تعداد ستون‌ها
- 💾 **ذخیره خودکار** تنظیمات و لیست تصاویر انتخاب‌شده
- ⏱️ **نمایش زنده** پیشرفت عملیات در زمان واقعی
- 🔊 **تولید ویدیو بدون صدا** به‌صورت پیش‌فرض (با امکان تنظیم دستی)
